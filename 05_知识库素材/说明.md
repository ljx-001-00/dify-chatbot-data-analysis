## 重新上传到 Dify 的步骤

1. 知识库「热水器产品」→ 删除旧文档（尤其是「百度安全验证」「1」这类误抓的网页内容，
   它们会与正常文档抢召回，导致答非所问）
2. 添加文档 → 导入已有文本 → 上传 `电热水器商品介绍.md`
3. **分段设置（关键）**：
   - 分段模式：通用
   - **分段标识符：`\n## `**（两个井号前带换行）—— 每个 `##` 标题自成一段
   - 最大分段长度：500
   - 分段重叠：50
   - 索引方式：高质量（向量检索）
4. 保存后做一次召回测试：输入 `R40-A0 额定功率`，应命中「R40-A0 储水式电热水器 40L」这一段。

> 若按 `\n\n` 切分，实测 chunk 只有 44~62 字符，标题与正文被切成两半，模型拿不到完整语义。

## 与数据库对齐

商品价格同时存在于两处：知识库文档（给模型看）和 MySQL `products` 表（给价格路由用）。
两者必须一致，否则会出现「文档说 4299、路由说 3999」的矛盾。

校验脚本：

```bash
python check_products.py
# 逐行打印 文档价格 vs 数据库价格，最后给出「全部一致 / 存在差异」
```

当前状态：6 个型号价格全部一致。

每个型号段落都包含：容量/功率/能效/内胆/尺寸/净重/售价/保修/月耗电，参数集中在一处，
