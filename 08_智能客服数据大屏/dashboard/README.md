# 热水器客服 · 聊天数据可视化大屏

基于 **PyCharm + Python Flask + Apache ECharts 5.6** 的本地数据可视化大屏，数据来自
`data_analysis/datacube_export/` 下的 7 份 CSV（与数据魔方平台同源）。

## 运行方式（PyCharm）

1. 用 PyCharm 打开本 `dashboard` 文件夹（File → Open）。
2. 右下角选择解释器（本机 Python 3.10 即可）。
3. 确认依赖：`pip install -r requirements.txt`（只需要 Flask）。
4. 运行 `app.py`，控制台会打印访问地址：<http://127.0.0.1:5001>。
5. 在 PyCharm 内置浏览器或任意浏览器打开该地址。

也可以直接双击 `run.cmd`（自动检查并安装 Flask，然后启动服务并打开浏览器）。

## 端口

默认 `5001`，如被占用：`set PORT=5002` 后再运行 `python app.py`。

## 页面内容

| 面板 | 图表 | 数据源 CSV |
|---|---|---|
| 情感分布 | 环形图（中心=负面占比、右侧图例含条数） | 情感分布.csv |
| 主题分布 | 玫瑰图（5 类诉求全期占比，按月取均值） | 月度主题趋势数据_长表.csv |
| 高频关键词 | 横向条形图 TOP12 | 聊天词语频次数据.csv |
| 月度主题趋势 | 堆叠面积图（5 主题） | 月度主题趋势数据.csv |
| 月度消息量 | 柱线复合（金色柱=峰值月） | 聊天密度月分布.csv |
| 24h 聊天密度 | 柱状图（金色柱+标记=峰值时段） | 聊天密度小时分布.csv |
| 情感趋势 | 多线面积图（正/中/负） | 情感趋势数据.csv |

顶部 KPI：总消息 22,575 / 覆盖 12 个月 / 峰值时段 10:00（1,673 条）/ 负面情绪 82.6%
（数字均由 API 实时算出，非写死）。

装饰资源复用此前为数据魔方生成的素材：
`static/img/`（bg.png、header-left/right.png、panel.png、title-bg.png）。

## 交互

- 全局 1920×1080 固定舞台，任意窗口尺寸等比缩放居中；
- 背景粒子连线 + 扫描光带（canvas）；
- 所有图表自动轮播 tooltip；KPI 数字滚动动画；底部指标跑马灯；
- 刷新页面即重新读取 CSV（CSV 更新后无需改前端）。

## 验收点

- `GET /health`：数据目录检查；
- `GET /api/dashboard`：与数据魔方口径一致（主题占比合计 100%，小时计数合计 22,575）。
